As sessões do Claude abrem nos repositórios git logo abaixo desta pasta.

Se um dia você tiver outra conta (outro emprego, por exemplo), cria outro espaço ao lado deste.

No Linear: Settings → Security & access → Personal API keys → New key.

Jira Cloud: id.atlassian.com → Segurança → Tokens de API. Server/Data Center: token pessoal no seu perfil.

Sem Linear nem Jira, você cria as tarefas no próprio quadro (“+ Nova tarefa”).

A chave SSH para clonar e dar push é criada depois, pelo botão “Configurar Bitbucket”.

Vale só nas pastas deste espaço. Sem ele, fica o do seu ~/.gitconfig.
